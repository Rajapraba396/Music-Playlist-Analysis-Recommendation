# Music Playlist Analysis and Recommendation System

## About the Project

This project analyzes music playlist data, explores relationships between audio features, groups similar songs using machine learning, and recommends songs based on audio similarity.

## Objectives

- Perform data preprocessing and cleaning.
- Analyze playlist genres, artists, popularity, and audio features.
- Visualize correlations between music features.
- Group similar songs using K-Means clustering.
- Visualize clusters using Principal Component Analysis (PCA).
- Recommend similar songs using cosine similarity.

## Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Project Workflow

1. Data collection and preprocessing
2. Exploratory Data Analysis (EDA)
3. Correlation matrix visualization
4. K-Means clustering
5. PCA cluster visualization
6. Cosine similarity-based song recommendations

## How to Run

1. Download or clone this repository.
2. Open the `.ipynb` notebook in Google Colab.
3. Upload the dataset when prompted, or update the dataset path.
4. Run the notebook cells in order.
5. Enter a song title to obtain recommendations.

## Results

The project generates exploratory visualizations, a correlation heatmap, song clusters, and recommendations for similar songs. Refer to the notebook for the actual results and plots.
